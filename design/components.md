Aashraya component notes

- Header: logo and wordmark on white; keyboard reachable Discover, How it works, and Register links; collapses to a single mobile menu.
- Buttons: primary maroon, secondary white with border, quiet link. Minimum 44px touch target, visible focus ring, disabled/loading states.
- Blood group filter: eight explicit buttons, selected state announced with aria-pressed; all blood groups remain available at mobile widths.
- Donor card: blood badge, student display name, department, campus area, availability, and connection action. Never show phone/email.
- Dialogs: native dialog, labelled heading, explicit close button, Escape support, form labels and submit feedback.
- Forms: visible labels, required indicators, browser validation, field hints, error summary/inline messages, consent text.
- Status toast: live region with concise confirmation; no assertion that a network request was sent.
- Demo banner: always identifies sample data and local-only behavior.
